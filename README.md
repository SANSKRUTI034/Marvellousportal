# Marvellousportal

## Overview
Marvellousportal is a Spring Boot application developed using Java and Maven.

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven

## Features
- Spring Boot application setup
- Database connectivity using MySQL
- REST API development

## Prerequisites
- Java JDK
- Maven
- MySQL Server

## How to Run
1. Clone this repository.
2. Configure your MySQL database and credentials locally.
3. Run the application using your IDE or Maven.
